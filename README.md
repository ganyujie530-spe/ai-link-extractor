# AI 链接提取 / AI Link Extractor

把 **ChatGPT、Gemini、Claude 的公开分享链接**导出成 Markdown。

这个仓库**只放打包好的安装包**（Windows 的 `.exe` 和安卓的 `.apk`），不含源代码。
拿来直接用就行。

## 下载

到右边的 **Releases（发布）** 页，下载最新一个版本里的文件：

- `AI_Link_Extractor_*.exe` —— Windows 电脑
- `AI_Link_Extractor_*.apk` —— 安卓手机

## 怎么用

**电脑（exe）**：双击打开，会弹出一个黑色窗口。把分享链接粘进去、回车，导出的 Markdown 存到桌面。
Claude 的链接会临时弹一个浏览器窗口来读取数据，读完可以关掉。

**手机（apk）**：安装后打开，粘贴分享链接、点「开始提取」，文件存到「下载 / AI链接提取」文件夹。

> 安装时手机 / 系统可能提示「来自未知来源」或要确认，这是正常的（没有上架应用商店的 App 都会这样）。
> 华为等部分手机每次安装都要手动确认几步。

## 支持的链接

- `chatgpt.com/share/…`
- `gemini.google.com/share/…`（或 `share.gemini.google/…`）
- `claude.ai/share/…`

导出的是**公开分享**的对话；私有、需要登录的链接取不到。
